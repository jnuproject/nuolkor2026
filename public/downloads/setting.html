OpenCode + NVIDIA 무료 LLM API 설정 가이드

새 노트북에서 OpenCode를 설치하고 NVIDIA(build.nvidia.com)의 무료 LLM API 키를 연결해 코딩 작업을 하는 방법을 순서대로 안내합니다.

위 탭으로 운영체제를 선택하면 해당 OS에 맞는 명령과 경로만 표시됩니다.

1. 사전 준비

  1. 터미널. 기본 Terminal.app으로 충분하며, WezTerm·Ghostty·Kitty 등을 써도 됩니다.
  2. 현재 Node.js LTS (npm으로 설치할 경우에만 필요).
  3. NVIDIA 계정. 없으면 build.nvidia.com에서 가입.
  1. Windows Terminal + PowerShell 7 권장. 기본 PowerShell도 동작합니다. OpenCode 공식 문서는 완전한 호환성을 위해 WSL 사용도 권장합니다.
  2. 현재 Node.js LTS (npm으로 설치할 경우에만 필요).
  3. NVIDIA 계정. 없으면 build.nvidia.com에서 가입.

2. NVIDIA API 키 발급 (무료)

이 단계는 운영체제와 무관하게 동일합니다.

1 build.nvidia.com에 접속합니다.
2 우측 상단 Sign in → 계정 생성 또는 로그인.
3 사용하려는 모델 페이지로 이동 (예. nemotron-3-super-120b-a12b, Llama, Qwen, GLM 계열 등).
4 페이지의 Get API Key 버튼 클릭 → Generate API Key.
5 발급된 키(nvapi-... 형태)를 안전한 곳에 보관합니다. 키는 여러 모델에 공용으로 사용 가능합니다.
무료 tier에는 호출 수/속도 제한이 있습니다. build.nvidia.com의 각 모델 페이지에서 사용량 한도를 확인하세요.

3. OpenCode 설치

3-1. 설치 스크립트 (권장)

curl -fsSL https://opencode.ai/install | bash

3-2. Homebrew

brew install anomalyco/tap/opencode

3-3. npm

npm install -g opencode-ai
설치 후 opencode --version으로 확인합니다. command not found가 나오면 설치 스크립트가 안내한 PATH 줄을 ~/.zshrc에 추가하고 source ~/.zshrc를 실행하세요.

3-1. 네이티브 — npm

npm install -g opencode-ai
설치 후 opencode --version으로 확인합니다. opencode : 용어가 ... 인식되지 않습니다 오류가 나오면 터미널을 새로 열어 PATH를 다시 읽게 하세요.

4. NVIDIA API 키 연결

두 가지 방법 중 하나를 선택합니다. (A) 인터랙티브 /connect, (B) 환경 변수.

방법 A. /connect 명령 사용 (권장)

1 작업할 프로젝트 디렉토리로 이동 후 OpenCode 실행. 
cd /path/to/project
opencode
cd C:\path\to\project
opencode
2 OpenCode 안에서 /connect 입력. 
/connect
3 목록에서 NVIDIA 선택.
4 발급받은 NVIDIA API 키 입력 후 Enter. 
┌ API key
│
└ enter
5 /models 로 사용 가능한 NVIDIA 모델 목록 확인 후 사용할 모델 선택. 
/models
키를 입력할 때는 화면 공유·프로젝터 송출을 잠시 끄고, 키를 채팅이나 코드 파일에 붙여 넣지 마세요. 연결 정보를 바꾸려면 /connect를 다시 실행하고, 노트북을 분실했다면 build.nvidia.com에서 즉시 키를 폐기(revoke)하세요.

방법 B. 환경 변수 사용

셸 프로파일(~/.zshrc, bash를 쓰면 ~/.bashrc)에 다음을 추가합니다.

export NVIDIA_API_KEY=nvapi-여기에-본인-키

변경 사항을 적용한 뒤 OpenCode를 실행합니다.

source ~/.zshrc
opencode

키 값을 화면에 출력하지 말고, 설정 여부만 다음과 같이 확인합니다.

if [ -n "$NVIDIA_API_KEY" ]; then
  echo "NVIDIA_API_KEY is set"
else
  echo "NVIDIA_API_KEY is not set"
fi

PowerShell에서 사용자 환경 변수로 영구 등록합니다.

[System.Environment]::SetEnvironmentVariable(
  'NVIDIA_API_KEY', 'nvapi-여기에-본인-키', 'User')

또는 명령 프롬프트(cmd)에서.

setx NVIDIA_API_KEY "nvapi-여기에-본인-키"

등록 후 터미널을 완전히 닫았다가 새로 열어야 값이 반영됩니다. 키 값을 출력하지 말고 설정 여부만 확인합니다.

# PowerShell
if ($env:NVIDIA_API_KEY) {
  "NVIDIA_API_KEY is set"
} else {
  "NVIDIA_API_KEY is not set"
}

# cmd
if defined NVIDIA_API_KEY (echo NVIDIA_API_KEY is set) else (echo NVIDIA_API_KEY is not set)
$env:NVIDIA_API_KEY = "..." 형태는 현재 세션에서만 유효합니다. 터미널을 닫으면 사라지므로 영구 설정에는 위의 SetEnvironmentVariable 또는 setx를 쓰세요.
OpenCode 공식 NVIDIA provider가 인식하는 환경 변수 이름은 NVIDIA_API_KEY입니다. 별도의 커스텀 provider 설정은 필요하지 않습니다.

5. 프로젝트 초기화 필수 X

처음 작업하는 프로젝트라면 AGENTS.md를 생성해 OpenCode가 코드베이스를 파악하도록 합니다. 건너뛰어도 OpenCode는 정상 동작하며, 코드베이스 이해도를 높이기 위한 선택 단계입니다.

cd /path/to/project
opencode
/init
cd C:\path\to\project
opencode
/init

생성된 AGENTS.md는 git에 커밋하는 것을 권장합니다.

6. 수업 모델 선택

NVIDIA가 제공하는 모델 목록은 바뀔 수 있으므로 이 문서에 특정 모델 ID를 고정하지 않습니다. OpenCode에서 /models를 실행하고, 목록에 실제로 표시되는 NVIDIA 모델 중 강사가 수업 당일 안내한 모델을 선택하세요.

1 OpenCode 안에서 모델 선택기 열기. 
/models
2 NVIDIA provider에서 강사가 지정한 모델을 선택하고 짧은 요청으로 연결을 확인합니다. 
Create only a one-line README.md that says "Setup complete."
Before editing, tell me the exact file you will change.
3 제안된 파일과 내용을 확인한 뒤에만 변경을 승인합니다. API 키나 개인정보는 프롬프트에 입력하지 않습니다.
모델을 전역 설정 파일에 직접 고정하는 것은 이 수업의 필수 단계가 아닙니다. 특정 모델 ID를 복사한 설정 파일은 모델이 교체되면 바로 고장날 수 있으므로, 수업에서는 /models에 현재 표시되는 목록을 기준으로 선택합니다.

8. 문제 해결

  • 모델 목록에 NVIDIA가 안 보임: 위의 값 비노출 명령으로 환경 변수 설정 여부를 확인. 설정되지 않았다면 source ~/.zshrc 후 재실행. 또는 /connect로 NVIDIA를 다시 연결.
  • opencode: command not found: 설치 경로가 PATH에 없습니다. ~/.zshrc에 export PATH="$HOME/.opencode/bin:$PATH"를 추가하고 source ~/.zshrc.
  • 모델을 못 찾음 (model not found): /models를 다시 열고, 목록에 실제로 표시되는 NVIDIA 모델을 선택하세요. 예전에 복사한 모델 ID나 임의로 줄인 ID는 사용하지 않습니다.
  • 401 / 인증 오류: build.nvidia.com에서 키가 유효한지 확인. 만료/삭제된 키는 새로 발급.
  • 429 / Rate limit: 무료 tier 제한. 호출 간격을 늘리거나 다른 모델로 전환.
  • 응답이 멈춤: 먼저 네트워크 상태를 확인하고, 새 세션에서 더 작은 요청으로 재시도하세요. 반복되면 강사에게 노란색 도움 신호를 보내세요.
  • 모델 목록에 NVIDIA가 안 보임: 위의 값 비노출 명령으로 환경 변수 설정 여부를 확인. 설정되지 않았다면 터미널을 새로 열어 재실행(setx는 기존 세션에 반영되지 않습니다). 또는 /connect로 NVIDIA를 다시 연결.
  • opencode 명령을 인식하지 못함: 터미널을 새로 열어 PATH를 다시 읽게 하세요. 그래도 안 되면 where.exe opencode로 설치 위치를 확인하고 해당 폴더를 사용자 Path 환경 변수에 추가.
  • 설정 파일이 안 읽힘: 탐색기에서 파일 확장명 표시를 켠 뒤 opencode.json.txt로 저장되지 않았는지 확인. 인코딩은 UTF-8(BOM 없음)이어야 합니다.
  • 모델을 못 찾음 (model not found): /models를 다시 열고, 목록에 실제로 표시되는 NVIDIA 모델을 선택하세요. 예전에 복사한 모델 ID나 임의로 줄인 ID는 사용하지 않습니다.
  • 401 / 인증 오류: build.nvidia.com에서 키가 유효한지 확인. 만료/삭제된 키는 새로 발급.
  • 429 / Rate limit: 무료 tier 제한. 호출 간격을 늘리거나 다른 모델로 전환.
  • 응답이 멈춤: 먼저 네트워크 상태를 확인하고, 새 세션에서 더 작은 요청으로 재시도하세요. 반복되면 강사에게 노란색 도움 신호를 보내세요.
